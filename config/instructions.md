Liebe Bewerberin, lieber Bewerber,

für die Bewerbung auf die W2-Professur „Psychologie in den Bildungswissenschaften“ der JGU Mainz fordert die Kommission ein RESQUE-Profil an. Mit dieser App können Sie das Profil erstellen. Folgende Informationen sind wichtig:

- Sie können beliebig viele Ihrer Publikationen in das Tool eintragen, aber **maximal 10 Publikationen** bei der Kommission einreichen. Um die Breite Ihres Profils abzubilden, empfehlen wir, alle 10 Plätze zu nutzen. Es müssen jedoch **mindestens 5 Publikationen** eingereicht werden.
  → Wenn Sie die Daten mit "Save to file ..." exportieren, wählen Sie also maximal 10 Publikationen aus.
- Bitte markieren Sie die **3 für die Professur einschlägigsten Publikationen** als "Top Papers".
- Es werden nur Publikationen ausgewertet, für die Sie alle Indikatoren **vollständig ausgefüllt** haben. Ob eine Publikation vollständig eingetragen ist, erkennen Sie an einem grünen Punkt neben der jeweiligen Publikation in der Übersicht (links) und daran, dass rechts oben keine Probleme angezeigt werden.
- Wenn Sie alle Publikationen eingegeben haben, exportieren Sie die Daten mit "Save to file ..." als `json`-Datei und reichen Sie diese zusammen mit Ihren anderen Unterlagen ein. Die Daten aus dem RESQUE-Tool werden *nicht* automatisch an die Kommission übertragen.

**Hinweis zum Datenschutz:** Die App läuft lokal im Browser auf Ihrem Rechner (auch offline), und Ihre Profildaten werden nur in Ihrem Browser gespeichert. Wenn Sie DOIs Ihrer Publikationen eingeben, werden diese an doi.org übermittelt, um Metadaten wie Titel, Jahr und Abstract abzurufen.
